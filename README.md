# QA-Demo
Това е проста демо 2D игра, създадена като учебен проект.

Файлове:
- `index.html` — основен HTML с Canvas.
- `style.css` — стилове за демо играта.
- `script.js` — логика за движение, събиране на точки и Game Over.

Как да стартираш:
1. Отвори `index.html` в браузъра.
2. Използвай стрелките за движение.
3. Събирай жълтите точки и избягвай червените врагове.
